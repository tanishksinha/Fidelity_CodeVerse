# 🛡️ Fidelity Behavioral Ghost SDK - Team Demo Guide

This guide explains how to set up and run the "Unstoppable Hybrid" demo for the Fidelity Ghost SDK. This branch (`feature/dom-extractor`) is fully configured to bypass strict CSP (Content Security Policies) on financial sites like Vanguard and Zerodha.

---

## 1. Prerequisites
Ensure you have the following installed on your machine:
- **Python 3.10+** (For the FastAPI backend)
- **Node.js / npm** (For the frontend/React app if needed)
- **Ngrok** (For creating the secure public tunnel)
- **Tampermonkey** browser extension (Installed in Chrome/Brave)

## 2. Getting the Code
Pull the latest code from the specific feature branch:
```bash
git fetch origin
git checkout feature/dom-extractor
git pull origin feature/dom-extractor
```

## 3. Backend Setup
You need to run the FastAPI backend which handles the AI priority cascade and telemetry ingestion.

1. Navigate to the backend directory:
   ```bash
   cd our_backend
   ```
2. Create and activate a virtual environment (optional but recommended):
   ```bash
   python -m venv venv
   # Windows:
   .\venv\Scripts\activate
   # Mac/Linux:
   source venv/bin/activate
   ```
3. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
4. **Environment Variables:** Ensure you have a `.env` file in the `our_backend` folder containing your `SUPABASE_URL`, `SUPABASE_KEY`, and `GOOGLE_API_KEY`.

## 4. Running the Stack
You will need **two separate terminal windows**.

**Terminal 1: Start the Backend**
```bash
cd our_backend
python main.py
```
*(The backend should now be running on `http://localhost:8080`)*

**Terminal 2: Start the Ngrok Tunnel**
```bash
npx ngrok http 8080
```
> **CRITICAL STEP:** Copy the `Forwarding` URL generated by ngrok (e.g., `https://random-words.ngrok-free.dev`). Open a browser tab, paste this URL, and click the blue **"Visit Site"** button to bypass the ngrok warning screen. Leave this tab open.

## 6. How to Run the Demo
1. Go to your target site (e.g., `vanguard.com`).
2. **Crucial Prep:** Press `F12` to open the console and type `localStorage.clear(); location.reload();`. This guarantees the popup shows up for the presentation.
3. Present the Popup: Enter fake details and hit Activate.
4. Prove persistence: Click any link to go to a new page. The popup won't annoy the user again.
5. **The Climax:** On the new page, click any random element 3 times rapidly (Rage Click). The Green AI Nudge will appear, and your backend terminal will light up with the event!
