Pre-Demo

Pre-Demo Checklist

Complete every item at least 5 minutes before judges arrive. Do not skip.

Services Running

  • npm run dev is running → localhost:3000 loads without errors
  • python main.py is running → terminal is visible and shows startup log
  • npx ngrok http 8080 is running → ngrok URL is live and accessible
  • Tampermonkey extension is installed in Chrome
  • God-Mode Synaptic script is pasted into Tampermonkey and enabled

Browser Setup

  • Tab 1 open: localhost:3000
  • Tab 2 open: wikipedia.org (or Vanguard)
  • F12 Console open on Wikipedia tab — confirm log says: 🛡️ SYNAPTIC GOD-MODE TAMPERMONKEY INJECTION STARTING...
  • Run localStorage.clear() in console on both tabs → fresh state
  • Backend terminal is visible (split screen or second monitor)
⚠️ 30-Second Cooldown Warning
The backend enforces a 30-second cooldown between AI interventions per session. If you already triggered a nudge while testing, wait 30 seconds or restart the backend before your live demo begins.
💡 Backup Plan
If the popup doesn't fire, open F12 console → type localStorage.clear() → reload the page → triple-click again. This resets the session instantly.
